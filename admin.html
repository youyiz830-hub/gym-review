🔥 Firebase 設定ガイド

クロスデバイスの重複防止には Firebase Firestore（無料） が必要です。
以下の手順で設定してください：

  1. console.firebase.google.com でプロジェクト作成
  2. 「Firestore Database」→「本番環境で開始」→ リージョン: asia-northeast1
  3. 「プロジェクト設定」→「アプリ」→ Webアプリを追加 → SDK設定をコピー
  4. js/config.js の FIREBASE セクションに貼り付け
  5. index.html の Firebase SDK コメントアウトを解除

※ 無料枠（Sparkプラン）：読み取り50,000回/日・書き込み20,000回/日・1GB。
ジム規模では無期限で無料枠内に収まります。
